# koishi-plugin-yesimbot-global-brain

全局脑插件：让同一个 Bot 在多个群聊和私聊之间共享知识、问题与经验。

它不会把所有会话的聊天记录合并成一个上下文，也不会把一个群的内容自动发到另一个群。全局脑更像 Bot 自己的跨会话大脑：某个会话把值得保留的内容放进去，其他会话按需读取，并自行判断要不要用、要不要发。

## 为什么需要

默认情况下，同一个 Bot 在不同会话里是彼此隔离的。群 A 看到的梗图，群 B 不知道；群 A 需要资料，群 B 也没办法帮忙。

全局脑解决的是同一人格的跨会话连续性：

- 群 A 存入一条梗图。
- 群 B 的 Bot 在下次自然行动时看到摘要。
- 群 B 的 Bot 根据本群气氛决定是否发送，以及怎么表达。
- 群 A 发布问题。
- 群 B/C 可以回答，或者问自己群里的群友，再把结果写回全局脑。

## 工作方式

全局脑中有四类内容：

- 分享：梗图、合并转发、文案等有趣内容。
- 问题：某个会话需要的信息。
- 回复：某个会话或群友给出的回答。
- 认知：某个会话形成的新结论或经验。

流程是：

1. 一个会话的 Bot 把内容放进全局脑。
2. 其他会话在自然行动时看到轻量摘要。
3. 当前会话的 Bot 自己判断是否读取、是否发送、怎么表达。
4. 如果有回复，回复会留在同一个全局脑 thread 里，发起问题的会话之后可以看到。

图片和工具文件会被保存为可重新物化的内容；其他会话读取时，当前会话会拿到一份本地可发送的版本。

## 最佳实践：让 Bot 跨群搬运梗内容

找到这两个文件：

```text
PERSONA.md
AGENTS.md
```

它们通常位于 YesImBot 的运行数据目录（`data/yesimbot`）下。`PERSONA.md` 会被自动创建；`AGENTS.md` 也会自动创建为空文件。如果文件已经存在，直接在里面追加内容即可。

### 在 `PERSONA.md` 中定义人格

`PERSONA.md` 负责“你是谁、你如何看待和表达”。要让 Bot 像一个人一样跨群分享，可以加类似内容：

```markdown
你有多个社交圈子。你会把某个圈子里有趣的内容记在心里，并尝试分享。
也可能在合适的圈子里提起。每个圈子气氛不同，你会用不同方式表达。
```

### 在 `AGENTS.md` 中定义行为规则

`AGENTS.md` 负责“具体情况下该怎么做”。要搬运梗内容，可以加类似内容：

```markdown
# 全局脑使用规则

## 分享链：来源侧（当前会话看到新内容）

- 当当前会话出现合并转发时，先积极查看完整内容，必要时使用 forward 读取工具。
- 如果里面有有意思的图片、梗、对话或值得分享的片段，静默存入全局脑。
- 不要替其他会话判断“他们会不会喜欢”，先放进去即可。
- 不要对群友汇报“存了、收了、丢进全局脑、转发给别的群”等机制。
- 看到有趣图片或梗文案时，同样静默记住并存入，不要只回复“保存了”。

## 分享链：接收侧（当前会话看到全局脑新内容）

- 当全局脑摘要提示有新分享、问题或回复时，先查看内容再决定。
- 如果适合当前会话，直接自然发出，像“刚看到的”“这个好草”；不要说明来自全局脑或其他群。
- 如果内容是合并转发，先查看完整内容，再决定是否分享或只分享其中一部分。
- 如果不适合，忽略即可，不要机械转发或刷屏。
- 如果需要信息，可以把问题写入全局脑；看到其他会话的问题时，如果本会话能帮忙，可以回答或询问群友。

## 禁止对外汇报机制

- 绝对禁止在发言中提及：全局脑、存入、转发给别的群、跨会话、已保存、已收取、打包丢进去、其他群会看到等机制性描述。
- 分享就是分享，像一个真人顺手把图发出来，而不是描述内部流程。
```

修改后需要让 YesImBot 重新加载对应会话。最简单的方式是重启 Koishi。

## 主要配置

| 配置项                   | 作用                                 | 默认值  |
| ------------------------ | ------------------------------------ | ------- |
| `storageDir`             | 全局脑存储位置；留空使用默认目录     | 空      |
| `maxDigestThreads`       | 每次自然行动最多提示几条新全局脑内容 | `5`     |
| `maxDigestReplies`       | 每次自然行动最多提示几条新回复       | `5`     |
| `maxDigestContentLength` | 摘要里每条内容最多显示多少字符       | `80`    |
| `maxBlobBytes`           | 图片/文件物化到全局脑的最大字节数    | `5 MiB` |
